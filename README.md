# E-Commerce-Performance-Analysis-using-Excel
This project focuses on analyzing e-commerce transactional data using Microsoft Excel to uncover meaningful business insights and present them through an interactive dashboard.

**Project Overview--
The E-Commerce Dashboard analyzes transactional sales data to uncover patterns related to orders, customers, products, shipping time, and satisfaction levels.


**Key Objectives --

Track overall sales and order performance

Understand customer buying behavior

Identify popular and high-performing products

Analyze order quantity and shipping time trends

Measure customer satisfaction levels


** KPIs & Metrics Used --

Total Orders

Total Sales

Order Quantity

Average Shipping Time

Customer Satisfaction Score

Product-wise Performance


**Dashboard Sections --

Trend Analysis – Sales and order trends over time

Order Quantity Analysis – Distribution and volume of orders

Buying Behaviour – Customer purchasing patterns

Popular Products – Best-selling and frequently ordered items

Shipping Time Analysis – Delivery efficiency insights

Customer Satisfaction – Satisfaction trends and performance


** Tools & Techniques --

Microsoft Excel

Pivot Tables & Pivot Charts

Data Cleaning & Formatting

Conditional Formatting

KPI Calculation

Interactive Dashboard Design


**Key Learnings --

Converted raw data into business insights

Designed clean and interactive dashboards

Thought like a data analyst for e-commerce use cases

Improvised storytelling using data visuals
